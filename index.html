U1FPGA · Cornell Electric Vehicles · Sep 2026 – now

FPGA CNN Accelerator

An FPGA accelerator for INT8 inference on LFD-RoadSeg, the ResNet-18 lane-segmentation network the CEV car drives on. We're prototyping on MNIST first. My part is the arithmetic: how wide every wire needs to be, and how to do fewer multiplies. That now includes a Winograd convolution unit in RTL that drops in for the direct 3×3 one.

  • Specified INT8 math with wide accumulators and multiply-and-shift rescaling, so there are no dividers in hardware
  • Sized the problem: one 3×3 RoadSeg layer is 1.1 B multiplies and 3.9 MB of memory per frame
  • Built a Winograd F(2×2, 3×3) convolution unit in SystemVerilog: 16 multiplies for a 2×2 output block instead of 36, with every transform done in adders
  • Integer-only by design: weights use 2G, so the hardware computes exactly 4× the direct result and a 2-bit shift undoes it
  • Testbench passes 100,006 vectors with 0 errors (100,000 random tiles plus corner cases) against a Python reference model
  • Sized the MNIST prototype's block RAM at 88.5 kB and drafted the FSM that sequences its conv and pool layers

module winograd_3x3_conv
(
    input  logic         [7:0] tile        [0:15],  // 4x4 pixels, row-major
    input  logic signed [11:0] u_weights   [0:15],  // G' g G'^T, precomputed
    output logic signed [19:0] convolution [0:3]    // 2x2 outputs, row-major
);
    always_comb begin
        // Input transform, rows: B^T d   (adders only)
        for (int c = 0; c < 4; c++) begin
            bt[0*4+c] = d[0*4+c] - d[2*4+c];
            bt[1*4+c] = d[1*4+c] + d[2*4+c];
            bt[2*4+c] = d[2*4+c] - d[1*4+c];
            bt[3*4+c] = d[1*4+c] - d[3*4+c];
        end
        // ...columns: (B^T d) B, same pattern

        // The only 16 multiplies
        for (int i = 0; i < 16; i++) begin
            m[i] = u_weights[i] * v[i];
        end

        // Output transform, rows: A^T m
        for (int c = 0; c < 4; c++) begin
            at[0*4+c] = m[0*4+c] + m[1*4+c] + m[2*4+c];
            at[1*4+c] = m[1*4+c] - m[2*4+c] - m[3*4+c];
        end
        // ...columns: (A^T m) A, same pattern

        // U' used 2G, so y is exactly 4x the direct result
        for (int i = 0; i < 4; i++) begin
            convolution[i] = 20'(y[i] >>> 2);
        end
    end
endmodule

Pose-Graph SLAM with a Sliding Window

The localization backend for CEV's autonomous car: a C++ pose-graph optimizer on ROS 2 that fuses LiDAR odometry and IMU. The sliding-window version keeps only the last 20 keyframes, so solve time stays flat no matter how long the car drives.

  • Gauss-Newton on a sparse information matrix with Eigen's SimplicialLDLT, 5 iterations per keyframe
  • New keyframe every 0.3 m or ~15°; oldest pose marginalized out past 20
  • Fixed a subtle bug where edges used a global-frame delta as the measurement, so the optimizer fought the odometry
  • SLAM running at 30 Hz on 3D LiDAR + IMU input

static constexpr int WINDOW_SIZE = 20;

void marginalize() {
    // Remove the sequential edge (0,1), the only edge incident to local index 0
    W_edges_.erase(std::remove_if(W_edges_.begin(), W_edges_.end(),
        [](const Edge2& e){ return e.i == 0 || e.j == 0; }), W_edges_.end());
    W_.pop_front();                              // drop oldest pose
    for (auto& e : W_edges_) { e.i--; e.j--; }   // shift window-local indices
}

// in odom_callback: new keyframe every 0.3 m or ~15 degrees
if (travel_dist > 0.3 || rotation_dist > 0.26) {
    double c = std::cos(last.th), s = std::sin(last.th);
    // measurement in the previous pose's body frame
    Eigen::Vector3d z(c*dx + s*dy, -s*dx + c*dy, wrapAngle(cur_th - last.th));
    W_.push_back({cur_x, cur_y, cur_th});
    W_edges_.push_back({(int)W_.size()-2, (int)W_.size()-1, z, info});

    if ((int)W_.size() > WINDOW_SIZE) marginalize();   // slide the window
    for (int it = 0; it < 5; ++it)
        gaussNewtonStep(W_, W_edges_, 1e-6);           // sparse H, SimplicialLDLT
}

def smiles_to_graph(smiles, y):
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return None
    x = torch.stack([atom_features(atom) for atom in mol.GetAtoms()])
    edge_index, edge_attr = [], []
    for bond in mol.GetBonds():
        i, j = bond.GetBeginAtomIdx(), bond.GetEndAtomIdx()
        edge_index += [[i, j], [j, i]]
        edge_attr  += [bond_features(bond), bond_features(bond)]
    edge_index = torch.tensor(edge_index, dtype=torch.long).t().contiguous()
    return Data(x=x, edge_index=edge_index, edge_attr=torch.stack(edge_attr),
                y=torch.tensor([y], dtype=torch.float))

export const K = 24;
export const START = 1500;

export function expected(a, b) {
  return 1 / (1 + 10 ** ((b - a) / 400));
}

// result is 1 if a wins, 0 if b wins, 0.5 for a draw ("too close to call").
export function eloUpdate(a, b, result = 1, k = K) {
  const delta = k * (result - expected(a, b));
  return [a + delta, b - delta];
}

// Score 0-10: rank sets the spread, so your favorite is always 10.
export function listScores(list) {
  const n = list.length;
  return Object.fromEntries(list.map((id, i) =>
    [id, Math.round((10 - (8 * i) / Math.max(n - 1, 1)) * 10) / 10]));
}
